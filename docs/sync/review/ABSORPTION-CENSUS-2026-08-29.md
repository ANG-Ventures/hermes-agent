## Why this census exists

NousResearch has **never direct-merged** one of our PRs — the merge-state field reads
`mergedAt: null` for all 130. That is *not* the same as rejection. Their integration
pattern is **consolidation + cherry-pick**: our commit is rebased onto current `main`
under a *different* PR number (often with a `Co-authored-by:` trailer), and our PR is then
closed with a pointer comment. Merge-state is therefore a useless oracle. **Content is the
oracle.**

## Method

1. **Enumerate** — `gh pr list --author "@me" --state all` → **130 PRs** (not ~60).
2. **Diff capture** — `gh pr diff <n>` for all 130 (7 exceeded GitHub's 20k-line / 300-file
   diff ceiling and were reconstructed from the `pulls/<n>/files` API).
3. **Snapshot** — `git archive origin/main` → read-only tree at `/tmp/mainsnap`
   (10,707 files). No checkout, no commit, no mutation of the working repo.
4. **Symbol probe** — up to 45 distinctive tokens per PR (defs, private helpers,
   error-message literals, config keys, CONSTANTS), each located tree-wide in the snapshot.
   Test-path symbols are down-weighted; source-path hits are the strong signal.
5. **Line probe** — every substantive added line (≥25 chars, non-trivial) matched
   *verbatim* against the snapshot, bucketed `src` / `test` / `doc`. This is the decisive
   measure: it answers "is our actual code text sitting on upstream's main today?"
6. **Topic-commit search** — `git log origin/main -i --grep=<topic words>` for the
   equivalent-shipped verdict.
7. **Close-reason mining** — last maintainer comment on every closed PR.

## Verdict definitions

| verdict | meaning | fork-side consequence |
|---|---|---|
| **ABSORBED** | Our code text / distinctive symbols are on `origin/main` now. | **Upstream copy is canonical.** Drop our divergent copy; reconcile to upstream. |
| **EQUIVALENT-SHIPPED** | Our symbols absent, but upstream shipped their own fix for the same defect. | **Converge candidate.** Delete our version, adopt theirs; keep only genuinely-extra surface. |
| **OUTSTANDING** | Neither our code nor an upstream equivalent is present. | **Rebase/carry candidate.** Still live work; keep the patch. |
| **SUPERSEDED-INTERNAL** | Closed by *us*/maintainer in favour of a newer PR of ours that is itself in this census. | Track the successor row, not this one. |

> `LINE-MATCH src%` below is the share of the PR's substantive **source** lines found
> verbatim on `origin/main`. ≥60% with distinctive symbols ⇒ ABSORBED. Low % with a
> matching upstream commit ⇒ EQUIVALENT-SHIPPED.

## Appendix B — Method caveats (read before trusting a row)

1. **A high `src%` can mean the OPPOSITE of absorption.** #71479 scored 57.2% and #80617 92.8%
   *because the code is still in the monolith we proposed to split* — the match proves the
   refactor did **not** happen. Always read the matched line.
2. **Shared scaffolding produces false positives.** #37418 scored 66.7% purely on
   `canonical_usage` dict fields upstream already had; #38976's 21% was upstream's own
   blocklist regex table; #62925's four string hits were upstream's posture-demotion renderer.
   Verdicts here were set from the *distinctive* line, not the score.
3. **`rg` respects `.gitignore`.** Probes ran via `subprocess` against a `git archive` snapshot
   (no ignore rules in play), but one interactive spot-check was corrupted by a shell resolving
   `rg` to BSD `grep` — which silently reported `build_recap` as absent. The #37381 row was
   corrected after re-verification. Any future re-run should use an absolute binary path.
4. **7 PRs exceeded GitHub's diff ceiling** (20k lines / 300 files) and were reconstructed from
   the `pulls/<n>/files` API: #49924, #59451, #64314, #64564, #67880, #75456, #83441. All seven
   are whole-fork pushes with no reviewable upstream payload.
5. **Line probes sample at most 400 substantive lines per bucket**, longest-first. For the
   mega-diffs the percentage is indicative only.
